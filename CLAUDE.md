# CLAUDE.md

## Stile di risposta
- Rispondi sempre in italiano.
- Rispondi in modo breve: massimo tre righe, salvo richiesta esplicita di approfondire.
- Niente riepiloghi lunghi di quello che hai fatto, niente elenchi di file toccati se non li chiedo.
- Se una cosa non è riuscita, dillo subito e in chiaro nella prima riga.

## Efficienza
- Non rileggere file interi se non serve: usa ricerche mirate (grep/glob) e leggi solo le porzioni necessarie.
- Non ripetere nella risposta il codice che hai appena scritto o modificato.
- Non produrre riepiloghi, elenchi di file o piani se non li chiedo esplicitamente.
- Una modifica alla volta: non anticipare lavoro non richiesto.
